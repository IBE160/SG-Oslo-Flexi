# SG-Oslo-Flexi
Repository for SG-Oslo-Flexi - IBE160 Programmering med KI.

## Getting Started

### Prerequisites
- Node.js (v20+)
- Python (v3.10+)
- Poetry (v2.0+)

### Installation

#### Frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

#### Backend
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   poetry install
   ```
